Dany jest ciąg parami różnych liczb u0, …, un, tzw. węzłów interpolacyjnych, oraz ciąg punktów p0, …, pn. Krzywa interpolacyjna Lagrange'a to krzywa wielomianowa p stopnia nie większego niż n, taka że p(ui) = pi dla każdego i.

Dana jest ona wzorem:

\(p(t) = \sum\limits_{i=0}\limits^{n}p_{i}(\prod\limits_{\substack{j = 0, …, n \\ j \ne i}}\frac{t\ -\ u_{j}}{u_{i}\ -\ u_{j}})\)

Punkt p(t) krzywej interpolacyjnej Lagrange'a możemy również wyznaczyć bezpośrednio stosując algorytm Aitkena.

Załóżmy, że znamy dwie krzywe, q i r, stopnia mniejszego niż n, z których pierwsza jest odpowiednią krzywą dla punktów p0, …, pn-1, a druga dla p1, …, pn. Wtedy krzywa

\(p(t) = \frac{u_{n}\ -\ t}{u_{n}\ -\ u_{0}}q(t) + \frac{t\ -\ u_{0}}{u_{n}\ -\ u_{0}}r(t)\)

jest finalną krzywą interpolacyjną. W istocie,

\(p(u_{0}) = 1 \cdot q(u_{0}) + 0 \cdot r(u_{0}) = p_{0}\)

\(p(u_{i}) = \frac{u_{n}\ -\ u_{i}}{u_{n}\ -\ u_{0}}p_{i}+\frac{u_{i}\ -\ u_{0}}{u_{n}\ -\ u_{0}}p_{i}=p_{i}\), dla i = 1, …, n - 1

\(p(u_{n}) = 0 \cdot q(u_{n}) + 1 \cdot r(u_{n}) = p_{n}\)

Zwróćmy uwagę, że dane na starcie punkty p0, …, pn są krzywymi poziomu 0, przecinającymi te punkty. Proces kreacji krzywych można więc wykonać rekurencyjnie. Dla określonego parametru t można zbudować właściwy punkt każdej z tych krzywych. Na początku wyznacza się n punktów stosownych dla parametru t na krzywych poziomu 1, będących rozwiązaniami dla par punktów p0p1, p1p2, …, pn-1pn. Następnie wyznacza się n - 1 punktów na krzywych poziomu 2, stanowiących odpowiedzi dla trójek punktów danych, itd. Każdy z obliczonych punktów jest pewną kombinacją afiniczną dwóch punktów znanych uprzednio. Cały algorytm można zapisać w następujacy sposób:

Dane:

  • n — stopień krzywej
  • t — parametr krzywej
  • p — punkty
  • u — węzły interpolacji
  • oldpts — poprzednie wartości punktów
  • newpts — nowe wartości punktów
Narzędzia:
  • console.log(m) — wydrukuj wiadomość m
var c = document.getElementById("canvas"),
    n = 4,
    t = 0,
    p = [600,500,1500,1300],
    u = [0, 100, 200, 300],
    oldpts = p,
    newpts = [];

for (var j = 1; j <= n; j++) {
	for (var i = 0; i <= n - j; i++) {
		newpts[i] = ((u[i + j) - t) / (u[i + j] - u[i]) * oldpts[i])
			+ ((t - u[i]) / (u[i + j] - u[i]) * oldpts[i + 1])
	}
	oldpts = newpts
}

console.log(newpts[0]) // Punkt p(t) krzywej p

Powyższy kod został maksymalnie uproszczony. Przede wszystkim, punkty początkowe są jednowymiarowe. Jednak drugi wymiar punktów można wyznaczyć analogicznie jednocześnie z pierwszym w przedstawionej podwójnej pętli. Narysowana w ten sposób krzywa złożona z punktów byłaby wciąż uproszczona, względem powyższego narzędzia, o zachowanie ciągłości, wielokolorowość, czy rysowanie interwałowe.
