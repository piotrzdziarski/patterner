Trójkąt Sierpińskiego

To jeden z najbardziej rozpoznawalnych fraktali. Poziom zerowy jest trójkątem równobocznym. Żeby otrzymać poziom pierwszy, połączono punkty znajdujące się w połowie długości poszczególnych boków; w ten sposób otrzymano trójkąt, który usunięto. Następnie, powtórzono tę operację dla pozostałych trzech trójkątów; dzięki czemu otrzymano fraktal poziomu drugiego itd.
Na następującym rysunku oznaczono wierzchołki, których współrzędne będą potrzebne w algorytmie:

Sposób realizacji zadania skłania do zastosowania mechanizmu rekurencji. Zastosowano pomocniczą funkcję triangle rysującą trójkąt o danych w parametrach współrzędnych. Zadbano o kolorystkę fraktala – jak na rysunku, pomarańczowo-białą. Pominięto wyznaczanie początkowych współrzędnych punktów A, B, i C na środku płótna i wielokolorowość. Trójkąt Sierpińskiego określono następującą specyfikacją problemu algorytmicznego:

Dane:

  • st – stopień fraktala;
  • ax, ay – współrzędne punktu początkowego A;
  • bx, by – współrzędne punktu początkowego B;
  • cx, cy – współrzędne punktu początkowego C;
  • c – płótno (ang. canvas).

Wynik:
Trójkąt Sierpińskiego poziomu st.

Narzędzia:

  • c.beginPath() – rozpocznij rysowanie nowej ścieżki;
  • c.moveTo(x, y) – ustalenie punktu początkowego (x, y);
  • c.lineTo(u, v) – wirtualne kreślenie odcinka od punktu (x, y) do (u, v);
  • c.fill() – wypełnij ścieżkę kolorem c.fillStyle.

Algorytm w języku JavaScript:

c.fillStyle = “#F15F04”;
triangle(ax, ay, bx, by, cx, cy);
Trojkat_Sierpinskiego(ax, ay, bx, by, cx, cy, st);
function Trojkat_Sierpinskiego(ax, ay, bx, by, cx, cy, st){
	if (st == 0) return;
	var abx, aby, acx, acy, bcx, bcy;
	bcx = (bx + cx) / 2;
	bcy = (by + cy) / 2;
	acx = (ax + cx) / 2;
	acy = (ay + cy) / 2;
	abx = (ax + bx) / 2;
	aby = (ay + by) / 2;
	c.fillStyle = ”#FFF”;
	triangle(abx, aby, bcx, bcy, acx, acy);
	Trojkat_Sierpinskiego(ax, ay, abx, aby, acx, acy, st - 1);
	Trojkat_Sierpinskiego(abx, aby, bx, by, bcx, bcy, st - 1);
	Trojkat_Sierpinskiego(acx, acy, bcx, bcy, cx, cy, st - 1);
}
function triangle(ax, ay, bx, by, cx, cy) {
	c.beginPath();
	c.moveTo(ax, ay);
	c.lineTo(bx, by);
	c.lineTo(cx, cy);
	c.fill();
}
